# FORCE V65

## Matchup semantic-color alignment
- Matchup unit bars now use the same FORCE rating bands as overall ratings: 0–40 red, 41–70 gold/yellow, 71–100 green.
- Matchup numeric unit values use the same semantic color as their bar.
- Team identity remains in logos/names rather than bar color.
- Exported matchup PNGs inherit the same semantic coloring because they are rendered from the same matchup DOM.
