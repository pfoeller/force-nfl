# FORCE V67

## Logo-only team marks
- Audited team-mark rendering across matchup, forecast, schedule, diagnostics, rankings, and export paths.
- Default compact team tokens now render the real logo only, not logo + abbreviation.
- Removed abbreviation fallback badges from active team marks.
- Export logo failures now remove the mark rather than inserting a team-code badge.
- Full team names remain beside logos anywhere the UI already needs a textual identity.
