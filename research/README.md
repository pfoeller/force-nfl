# QB carryover experiment sources

These are the exact exploratory scripts used for the QB injury carryover decision documented in `../QB_CARRYOVER_RESEARCH.md`. They are research artifacts, not production model code.

`qb_carryover_synth_test.py` and `qb_baseline_rate_synth.py` are intended to be run from the original Celo model checkout because they import `config.py`, `elo.py`, `qb.py`, `data.py`, and `sample_data/tuned_config.json`. `qb_focus_test.py` records the focused comparison used for the v6 decision.
