# FORCE V92 - same-model Penalty WPA

V92 fixes a structural WPA inconsistency that remained in V91.

- V91 compared nflverse's stored `home_wp_post` for the enforced result against a counterfactual generated by FORCE's packaged nflfastR no-spread model.
- V92 scores **both** states with the same packaged nflfastR model.
- The enforced state comes from the first subsequent valid scrimmage row in the same game, which already contains the exact post-enforcement possession, down, distance, spot, score, clock, and timeout state.
- The no-penalty state continues to be reconstructed from the flagged play.
- Source `home_wp_post` is retained only as an audit field/fallback for rare end-of-half or special-state cases.
- The current-season-only 40/25/20/15 Penalty Impact blend is unchanged.
- V92 uses new 2025 calibration and 2026 game-flow cache keys.
