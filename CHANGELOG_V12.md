# FORCE V12

## Team identity on matchup pages

- Added self-contained team-color helmet marks to matchup headers.
- Helmets face into the matchup in the two-team hero and use each franchise's primary/secondary palette.
- Added compact helmet marks to matchup context cards, offense-vs-defense cards, strengths/weaknesses cards, team directory cards, and team profile headers.
- Kept marks as inline SVG/CSS instead of remote images so FORCE still works offline and PNG exports remain self-contained.
- No model math, forecasts, rankings, or diagnostics changed in this release.
